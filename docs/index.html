FAQ

Questions people ask before buying.

Which models can I use?

Anything LiteLLM supports: OpenAI, Anthropic, Gemini, Groq, Ollama and more. Set DEFAULT_MODEL once or pick a model per agent in the editor. You bring your own API keys.

What do I need to run it locally?

Node, Python 3.11+, Docker and the Supabase CLI. cp .env.example .env, then make dev starts Supabase locally and the API and web apps. API docs are at /docs.

Does it include billing or Stripe?

No. It includes token and cost metering, usage pages and monthly budgets per workspace. Charging your customers is up to you, and you can wire in whichever billing provider you prefer.

What is the difference between Starter and Agency?

Starter is the full product foundation for one agent product you own. Agency adds three CrewAI crews, the white-label client portal with a client role, deploy scripts for Supabase, Railway, Vercel and Modal, and a license that covers client work and white-label resale.

How is it delivered and how do updates work?

You download a zip from Gumroad right after checkout (currently v1.0.2). Updates to the version you bought show up in your Gumroad library. There is no license server and nothing phones home.

Is there a hosted demo I can log into?

Not yet. A hosted sandbox would need a model key with a spending cap and would expose the paid code to abuse. Instead there is a nine-screen click-through tour of the real app, and a 14-day refund if it is not what you expected once you run it.

How secure is the multi-tenancy?

Every table has row-level security, including the vector memory table, and the API queries as the signed-in user. A test seeds two customers with near-identical documents and checks that searches, raw SQL, inserts and deletes never cross workspaces. There has been no outside audit, and the tests ship with the code so you can run them yourself.

Can I use it for client projects?

Yes, with the Agency tier. Its license covers client work and white-label, multi-tenant resale of what you build. Starter covers one product you own.

What if it is not for me?

Email within 14 days and you get a refund, no questions asked. Problems getting it running are fixed first if you want them fixed.
